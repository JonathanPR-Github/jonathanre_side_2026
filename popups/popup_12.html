"GAMEBANANA COLLECTION"

2026

Prior to creating some unique mods on Gamebanana, i used the platform to update my Deathrun maps so server hosters could get the latest versions more efficently than on Steam

Somethime prior to the release of the Total Overhaul mod for TF2 called "Team Fortress 2 Classified", after having played the game for a bit, i felt like i wanted to help improve the game in a way before it released with a mod that could contiune that hype of the release

I first made a very simple mod that would work with all the variation total overhaul mods for TF2, called "Round Control Point Icons" that would change the control point icon, too look more like a control point. Simple enough

Then soon after i had made that mod, i made another one that would also work with all the other TF2 variations, called "Detailed Payload Icons" that changed the payload icons, so they looked more the payload. Pretty simple there too

Both mods released to positive reception, with them being praised for the idea and simplicity around the mods usage.
